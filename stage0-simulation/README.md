## 시뮬레이션 모터 파라미터

| 항목 | 값 |
|---|---|
| 상저항 Rs | 0.5Ω |
| 인덕턴스 Ls | 1.0mH (SPMSM, Ld = Lq) |
| 자속쇄교 λ | 0.01Wb |
| 극쌍수 p | 4 |
| DC 링크 전압 | 24V |
| 전류 제한 | 10A |
| 전류 루프 / 속도 루프 주기 | 10kHz / 1kHz |

## 규약

- Clarke 변환: 크기 불변(amplitude-invariant) 형식, 계수 2/3
- 전기각 θe = 0일 때 d축 = a상 축
- 토크: Te = 1.5 · p · λ · iq (SPMSM이라 릴럭턴스 토크 없음)
