# 모터 이론 학습

전자공학 전공이라 회로·제어는 배웠지만 전동기는 처음, 프로젝트와 병행해서 전동기 이론을 기초부터 공부한 기록

## 구성

| 파일 | 내용 |
|---|---|
| [checklist.md](checklist.md) | 모듈 A~K, 64개 학습 항목과 스스로 점검할 질문 |
| [notes/](notes/) | 공책에 정리한 내용을 모듈별로 옮긴 노트 |

## 진행 방식

1. 체크리스트 순서대로 공부하며 공책에 손으로 정리
2. 공책 내용을 모듈별 노트로 옮겨 커밋
3. 점검 질문에 노트 없이 답할 수 있으면 체크리스트에 체크

## AI 활용

- 학습 항목 구성과 점검 질문: Claude가 커리큘럼 초안 작성, 직접 검토 후 사용
- 공책 → 노트 정리: 직접 쓴 공책 내용을 Claude가 마크다운으로 옮기고 다듬음
- 공책에 없는 보충 설명은 노트 안에 `> Claude 보충` 표시로 구분
- 질문하며 이해한 내용은 노트의 "질문과 답" 항목에 기록
