# 01. PMSM과 FOC 기초

## PMSM 개요

PMSM(Permanent Magnet Synchronous Motor, 영구자석 동기 전동기): 회전자에 영구자석이 있고, 고정자 3상 권선이 만드는 회전 자기장을 따라 회전자가 같은 속도로 도는 모터

- 회전자가 자기장과 동기해서 회전하므로 "동기" 모터
- 높은 출력 밀도와 효율, 작은 토크 리플
- 주요 용도: 전기차, 드론, 로봇, 가전, 전기자전거 허브모터

| 종류 | 구조 | 특징 |
|---|---|---|
| **SPMSM** (표면부착형) | 자석이 회전자 표면에 부착 | Ld ≈ Lq |
| **IPMSM** (매입형) | 자석이 회전자 내부에 매입 | Ld < Lq, 릴럭턴스 토크 추가 활용 가능 |

제어의 핵심: **회전자 각도 파악 + 그 각도에 맞춘 3상 전류 인가** (브러시가 없기 때문)

## FOC (Field-Oriented Control, 벡터 제어)

3상 교류 모터를 DC 모터처럼 다루는 방식, 현업 표준

```
상전류 측정 (ia, ib, ic)
  → Clarke 변환 : 3상 → 2축 고정좌표 (α, β)
  → Park 변환   : 회전자 각도 θ로 → 회전좌표 (d, q)
  → d축 전류(자속), q축 전류(토크)를 각각 PI 제어
  → 역 Park 변환 → SVPWM → 3상 인버터 → 모터

바깥 루프: 속도 루프 → (그 바깥) 위치 루프
```

- **d축 전류 Id**: 자속 성분
- **q축 전류 Iq**: 토크 성분
- 회전좌표 변환 후 두 전류가 DC 값이 되므로 PI 제어기로 처리 가능

### 전류 지령 방식

| 방식 | 내용 | 주 용도 |
|---|---|---|
| **Id = 0 제어** | 자속 전류를 0으로 두고 Iq로만 토크 제어 | SPMSM, 입문용 |
| **MTPA** (Maximum Torque Per Ampere) | 음의 Id를 섞어 릴럭턴스 토크까지 활용, 전류당 토크 최대화 | IPMSM |
| **약계자 제어** (Field Weakening) | 고속에서 역기전력이 버스 전압을 넘지 않도록 음의 Id 주입 | 고속 운전 영역 확장 |
| **MTPV** | 약계자 영역보다 더 고속에서 전압당 토크 최대화 | 초고속 영역 |

### 전류 PI 게인 설계 (극점 상쇄)

전류 루프 목표 대역폭 ωc 기준

```
Kp = L · ωc
Ki = R · ωc
```

따라서 **모터 상저항 R과 인덕턴스 L 측정이 선행 조건**

## 회전자 위치 검출

| 방식 | 특징 |
|---|---|
| 엔코더 (자기식·광학식) | 정밀, 저속·정지에서도 정확, 본 프로젝트는 AS5048A(14비트 SPI 자기식) 사용 |
| 레졸버 | 견고, 산업·차량용 |
| 홀센서 | 저렴, 낮은 분해능(60° 단위) |
| **센서리스** | 중·고속: 역기전력 관측기(SMO 등), 저속·정지: 고주파 주입(HFI) |

### 엔코더 정렬 주의점

```
전기각 = 기계각 × 극쌍수
```

- GM4108H는 24N22P 구조로 **극쌍수 11**
- 기계각 오차가 전기각에서 11배로 증폭되므로 엔코더 자석 정렬과 영점 보정이 중요

## 기타 제어 방식

- **DTC (Direct Torque Control)**: 좌표 변환 없이 토크와 자속을 히스테리시스로 직접 제어, 빠른 응답, 큰 토크 리플
- **MPC (Model Predictive Control)**: 모델 기반으로 다음 상태를 예측해 최적 스위칭 선택, 큰 연산량, 최근 활발한 연구 분야
