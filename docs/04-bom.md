## 연결 구성 (1단계)

```
[220V] → GST25A12-P1J + 한국형 코드 → 12V 2.1mm 배럴
       → Adafruit 368 → 20AWG 빨강/검정 → IHM07M1 전원 단자

[PC] → USB → NUCLEO-G474RE ← (Morpho) → IHM07M1
                   │                          │
                   │ SPI (M-F 점퍼, 15cm 이하)  │ U/V/W 나사 단자 ← M-M 점퍼 ← 모터 F 듀폰
                   │                          │
                AS5048A ───────────────── GM4108H
```

- SPI 선은 짧게, 모터 3상 선과 이격 배치
- SPI 핀은 IHM07M1 사용 핀(PWM·ADC·인에이블)과 겹치지 않게 선택
- 연결 전 멀티미터로 단자 극성과 12V 출력 확인

## GaN 보드 (3단계) 계획

부품 개별 구매 없이 **PCB + 부품 포함 SMT 조립(PCBA)** 위탁

| 블록 | 주요 부품 |
|---|---|
| 파워단 | TI LMG2100R044 × 3 |
| 전류 센싱 | 10~20mΩ 션트 + INA241 (인라인) |
| 전압 센싱 | DC 버스 분압, 3상 상전압 분압 (센서리스용) |
| 전원 | 24V → 5V 벅 (LMR38010), 3.3V LDO |
| 보호 | 퓨즈, 역극성 보호, TVS, 과전류 비교기, NTC/TMP61, HI/LI 풀다운 |
| 커넥터 | XT30, 모터 단자, Nucleo 연결 헤더 |
| PCB | 4층 (전원 루프 최소화, 끊김 없는 GND 면) |

- 설계 전 조립 업체(JLCPCB, PCBWay 등)의 LMG2100R044·INA241 재고 확인
- 예상 비용: PCB 5장 + 조립 + 부품 약 ₩200,000 (대략값)
