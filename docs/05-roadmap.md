# 05. 로드맵과 안전 수칙

## 진행 순서

1. 시판 드라이버(IHM07M1)로 FOC 펌웨어 선행 완성
2. 병행하여 GaN 보드 설계 및 PCBA 주문 (제작·배송 2~3주)
3. 보드 도착 후 동일 펌웨어로 드라이버만 교체하여 검증

각 마일스톤 완료 시 코드와 학습 기록(Claude 도움 내용 포함)을 함께 커밋

## 마일스톤

| # | 내용 | 확인 방법 |
|---|---|---|
| 1 | 개루프(V/f) 모터 구동 | 전압 벡터 회전 시 모터의 부드러운 회전 여부 |
| 2 | AS5048A SPI 읽기, 전기각 영점 정렬 | 수동 회전 시 각도 변화의 연속성, 극쌍수 11 반영 여부 |
| 3 | 전류 오프셋 보정 | 정지 시 전류 0, 3상 전류 합이 0에 근접하는지 |
| 4 | **전류 루프 (Id = 0, Iq 지령)** | 토크 모드에서 Iq 지령 추종 여부 (최대 고비) |
| 5 | 속도 루프, 위치 루프 | 속도·위치 지령 추종, 오버슈트 |
| 6 | GaN 보드 교체 | 저전압부터 시작, 스위칭 노드 파형과 데드타임 확인 |
| 7 | (보너스) 센서리스 관측기(SMO) | 엔코더 값을 기준으로 추정 각도 비교 |
| 8 | (보너스) PWM 주파수 스윕 | 20/40/80/100kHz에서 효율·발열·리플 비교 |

## 소프트웨어

- STM32CubeIDE, CubeMX: 개발 환경, 타이머·ADC 설정
- SimpleFOC (PlatformIO): 초기 구동용, 이후 자체 구현 FOC로 교체
- ST MC SDK (Motor Control Workbench): 자체 구현 시 비교 기준
- STM32CubeMonitor 또는 시리얼 플로터: Id, Iq, 속도 실시간 그래프
- KiCad: GaN 보드 설계
- Python (numpy, matplotlib): 로그 분석, 간단한 시뮬레이션

## 학습 항목

- [ ] Clarke/Park 변환, SVPWM
- [ ] 전류 PI 게인 설계 (Kp = L·ωc, Ki = R·ωc)

- [ ] LMG2100R044 데이터시트, TIDA-010936 회로도·레이아웃 분석

## 안전 수칙

- 초기에는 **낮은 전압 제한**으로 시작 (SimpleFOC `voltage_limit` 2~3V 등), 12V 어댑터는 전류 제한 기능 미지원
- 전원 인가 순서: **로직(5V/3.3V) 먼저, 모터 전원(DC 버스) 나중**
- 펌웨어 기본값은 **PWM 꺼짐**, 과전류 감지 시 즉시 PWM 차단
- 손이 바로 닿는 위치에 비상 차단 스위치 배치
- 새 보드 첫 전원 인가는 **모터 분리 상태**에서
- 어댑터 연결 전 멀티미터로 극성과 전압 확인
- 로직 분석기·스코프 입력 범위를 넘는 노드(스위칭 노드, DC 버스)에 직접 연결 금지
