# 03. 하드웨어 선정

## 모터: iFlight GM4108H-120T (AS5048A 엔코더 포함)

1단계 목적은 **알고리즘 검증**, 따라서 안전하고 다루기 쉬운 짐벌 모터로 시작

| 항목 | 값 |
|---|---|
| 구성 | 24N22P (극쌍수 11) |
| 권선 | 120턴, 상저항 약 11Ω |
| 동작 전압 | 3~5S (약 11~18V) → 12V 어댑터로 구동 |
| 축 | 중공축 Ø10mm |
| 엔코더 | AS5048A (14비트, SPI/PWM 출력), 알루미늄 케이스 |
| 무게 | 약 137g (엔코더 포함) |

선정 이유

- 큰 상저항으로 12V에서도 전류 1A 안팎, 제어 오류 시에도 드라이버 손상·급회전 위험 최소화
- 엔코더 동봉으로 FOC 각도 검증 용이
- SimpleFOC, ODrive 등 오픈소스 스택에서 널리 쓰여 참고 자료 풍부

주의: AS5048A는 **SPI·PWM 출력만 지원, ABZ 출력 없음** → 드라이버 보드 엔코더 커넥터 대신 Nucleo SPI 핀에 직접 연결

## 모터 선정 기준 (전 단계 공통)

- **전압 24~48V 이하**: 100V급 GaN 부품과 호환, 안전
- **위치 센서 내장 또는 장착 가능**: 엔코더로 FOC 검증 후 센서리스 전환 목적
- **파라미터(R, L, Kt/Ke, 극쌍수) 공개**: 전류 게인 설계에 필요
- **너무 작지 않은 인덕턴스**: 드론용 아웃러너는 작은 L로 전류 리플이 커서 첫 전류 루프 튜닝에 불리, 단 GaN 고속 PWM 실험용으로는 적합

## MCU: STM32 NUCLEO-G474RE

- 모터 제어용 고급 타이머, PWM 동기 ADC, CORDIC(삼각함수 가속기)
- STLINK-V3E 디버거 내장 (Micro-USB)
- SimpleFOC, ST MC SDK 예제 모두 사용 가능
- 대안: TI LAUNCHXL-F280039C (TI GaN 레퍼런스 펌웨어를 그대로 참고할 경우)

## 시판 드라이버: X-NUCLEO-IHM07M1 vs IHM08M1

자작 GaN 보드로 바로 시작 시 펌웨어 문제와 하드웨어 문제 구분 곤란 → 시판 드라이버로 펌웨어 선행 검증

| 항목 | IHM07M1 | IHM08M1 |
|---|---|---|
| 파워단 | L6230 원칩 (드라이버 + FET 통합) | L6398 게이트 드라이버 + STL220N6F7 MOSFET (개별 소자) |
| 입력 전압 | 8~48V | 8~48V |
| 전류 | 실효 1.4A / 피크 2.8A | 실효 약 15A / 과전류 보호 30A 피크 |
| 션트 저항 | 0.33Ω | 약 10mΩ |
| 전류 센싱 | 3션트 / 1션트 선택 (로우사이드) | 3션트 / 1션트 선택 (로우사이드) |
| Nucleo 호환, 홀/엔코더 커넥터, ST SDK | O | O |
| 용도 | **1단계 (짐벌 모터)** | **2단계 (57BL 모터), Si vs GaN 비교** |

### 전류 측정 분해능 비교 (대략값)

| 항목 | IHM07M1 | IHM08M1 |
|---|---|---|
| 션트 × 증폭 게인 | 0.33Ω × 약 1.53 | 10mΩ × 약 5 (대략값) |
| 감도 | 약 0.50 V/A | 약 0.05 V/A |
| 12비트 ADC(3.3V) 1A당 카운트 | 약 627 | 약 62 |

- 짐벌 모터 동작 범위는 0.2~1A → IHM07M1이 **약 10배** 세밀한 전류 측정 가능
- IHM08M1은 전류 신호가 노이즈에 묻혀 전류 루프 튜닝에 불리

## PWM 스위칭 주파수

| 전력 소자 | 일반적인 주파수 |
|---|---|
| Si IGBT | 2~16kHz |
| Si MOSFET (저전압) | 16~30kHz (20kHz 전후가 가장 일반적) |
| SiC MOSFET | 10~50kHz |
| GaN FET | 40~100kHz 이상 |

- 20kHz 미만은 가청 대역이라 모터 고주파음 발생
- 1단계(IHM07M1 + 짐벌 모터): **20~25kHz**
- 3단계 GaN 보드: 20kHz에서 안정성 확인 후 40 → 80 → 100kHz로 올리며 비교

## 측정 장비 판단

### 오실로스코프 대역폭

대역폭 결정 요인은 PWM 주파수가 아닌 **엣지 상승 시간**

```
신호 대역폭 ≈ 0.35 / 상승시간
보이는 상승시간 = √(신호² + 스코프²)
```

| 측정 대상 | 상승 시간 | 필요 대역폭 |
|---|---|---|
| 상전류, 센서 출력, PWM 타이밍, SPI | - | 50~100MHz |
| IHM07M1 / IHM08M1 스위칭 노드 | 수십 ns | 100MHz |
| LMG2100 GaN 스위칭 노드 | 약 1~5ns | 200MHz(확인용), 350~500MHz(정밀 측정) |

GaN 엣지 2ns 기준 측정 오차: 200MHz 약 +33%, 350MHz 약 +12%, 500MHz 약 +6%

**결정**: 1단계는 오실로스코프 없이 시리얼 플로터, 멀티미터, GPIO 토글로 진행, **GaN 보드 PCB 주문 시점**에 12비트 200MHz 4채널급(예: Siglent SDS824X HD) 구매 또는 대여

### 로직 분석기(Saleae) 대체 가능 여부

- 가능: 3상 PWM 6채널 동시 기록, SPI 디코딩, 증폭기 출력(0~3.3V), 장시간 기록
- 불가능: GaN 스위칭 노드 파형, 링잉, 오버슈트 (아날로그 대역폭 1~5MHz)
- 주의: 아날로그 입력 범위(Logic 8: 0~5V, Pro: ±10V)를 넘는 스위칭 노드나 DC 버스에 직접 연결 금지

## GaN 파워단: TI LMG2100R044

- 90V 연속 / 100V 펄스, 35A 하프브리지
- 게이트 드라이버와 GaN FET 2개를 한 패키지에 통합
- 참고 레퍼런스: TI TIDA-010936 (12~60V 3상, LMG2100R044 × 3, 40kHz에서 최대 효율 99.3%)
- 짐벌 모터용은 레퍼런스의 1mΩ 션트 대신 **10~20mΩ** 사용으로 분해능 확보 (풋프린트 공용 설계)
- 데드타임 자동 삽입 기능 없음 → MCU 타이머에서 설정
