# firmware

STM32 NUCLEO-G474RE용 FOC 펌웨어 위치 (진행 예정)

- 1차: SimpleFOC 기반 (IHM07M1 + GM4108H + AS5048A)
- 2차: 자체 구현 FOC (Clarke/Park, SVPWM, 전류·속도·위치 루프)

Claude가 작성하거나 크게 수정한 코드는 파일 상단 또는 해당 함수에 주석으로 표시
